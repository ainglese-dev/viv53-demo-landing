# VIV53 Deployment Guide

## Quick Deploy

The site automatically deploys when code is pushed to the `main` branch via GitHub Actions.

### Deployment Workflow
1. Make changes on feature branch
2. Test locally: `npm run build && npm run preview`
3. Run tests: `npx playwright test`
4. Merge to `main` branch
5. GitHub Actions automatically builds and deploys
6. Site updates at https://www.viv53.com

### Prerequisites

## Environment Variables

### Production Configuration

Environment variables are stored as **GitHub Repository Secrets** and injected during the build process.

**To add/update secrets:**
1. Go to repository Settings → Secrets and variables → Actions
2. Click "New repository secret"
3. Add each variable from the list below

### Required Secrets

| Secret Name | Description | Example/Notes |
|-------------|-------------|---------------|
| `VITE_GA4_ID` | Google Analytics 4 Measurement ID | `G-XXXXXXXXXX` |
| `VITE_GTM_ID` | Google Tag Manager Container ID | `GTM-XXXXXXX` (optional) |
| `VITE_META_PIXEL_ID` | Meta (Facebook) Pixel ID | `XXXXXXXXXXXXXX` (optional) |
| `VITE_WHATSAPP_NUMBER` | WhatsApp number for contact button | `12345678900` (no + or spaces) |
| `VITE_CONTACT_FORM_URL` | FormSubmit.co endpoint for contact form | Auto-generated by FormSubmit |
| `VITE_BOOKING_FORM_URL` | FormSubmit.co endpoint for booking form | Auto-generated by FormSubmit |
| `VITE_ENABLE_SPANISH` | Enable Spanish language toggle | `true` or `false` |
| `VITE_APP_URL` | Production URL | `https://www.viv53.com` |
| `VITE_APP_NAME` | Application name | `VIV53 IT Services` |

### Local Development (.env)

For local development, copy `.env.example` to `.env` and fill in your values:

```bash
cp .env.example .env
```

**Note:** The `.env` file is gitignored and should never be committed.

## GitHub Actions Workflow

### Automated Deployment

**File:** `.github/workflows/deploy.yml`

**Triggers:**
- Push to `main` branch
- Manual workflow dispatch (Actions tab → Deploy to GitHub Pages → Run workflow)

**Process:**
1. Checkout code
2. Setup Node.js 18 with npm cache
3. Install dependencies (`npm ci`)
4. Build project (`npm run build`)
   - Environment variables injected from GitHub Secrets
5. Upload build artifacts
6. Deploy to GitHub Pages

**View Deployment Status:**
- Repository → Actions tab
- Click on latest workflow run
- Check build/deploy logs

### Testing Workflow

**File:** `.github/workflows/playwright.yml`

Runs Playwright tests on:
- Push to any branch
- Pull requests

## GitHub Pages Configuration

### Repository Settings

**Path:** Repository → Settings → Pages

**Required Configuration:**
- **Source:** Deploy from a branch
- **Branch:** `gh-pages` / `root` (auto-created by GitHub Actions)
- **Custom domain:** `www.viv53.com`
- **Enforce HTTPS:** ✅ Enabled

### DNS Configuration

**Domain:** www.viv53.com

**Required DNS Records:**
```
Type: CNAME
Host: www
Value: ainglese-dev.github.io
TTL: 3600
```

**Verification:**
```bash
dig www.viv53.com
# Should show CNAME pointing to ainglese-dev.github.io
```

**SSL Certificate:**
- Automatically provisioned by GitHub Pages
- Can take up to 24 hours after DNS configuration
- Check: Repository Settings → Pages → "HTTPS certificate"

## Analytics Setup

### Activating Analytics (Post-Deployment)

The analytics code is implemented but commented out by default. To activate:

1. **Get Tracking IDs:**
   - **GA4:** https://analytics.google.com/ → Admin → Data Streams → Measurement ID
   - **GTM:** https://tagmanager.google.com/ → Container ID
   - **Meta Pixel:** https://business.facebook.com/events_manager → Pixel ID

2. **Add to GitHub Secrets:**
   - Add `VITE_GA4_ID`, `VITE_GTM_ID`, `VITE_META_PIXEL_ID`

3. **Uncomment Analytics Code:**
   - **File:** `src/lib/analytics.ts`
   - Uncomment GTM and Meta Pixel initialization blocks
   - Commit and push to `main`

4. **Verify Tracking:**
   - Visit site and accept cookie banner
   - Check GA4 Real-Time reports
   - Check GTM Preview mode
   - Check Meta Pixel Events Manager

# 4. Check GA4 Real-Time reports for:

## Troubleshooting

### Issue: 404 on Page Refresh

**Cause:** GitHub Pages doesn't natively support SPA routing

**Solution:** Verify `dist/404.html` exists after build
```bash
npm run build
ls dist/404.html  # Should exist
cat dist/404.html # Verify redirect script
```

### Issue: Blank Page After Deployment

**Cause:** Incorrect `base` path in Vite config

**Solution:** Check `vite.config.ts`
```typescript
export default defineConfig({
  base: '/',  // Should be '/' for custom domain
  // ...
})
```

### Issue: CSS Not Loading

**Cause:** Asset path mismatch

**Solution:**
1. Clear browser cache
2. Hard refresh (Cmd+Shift+R / Ctrl+Shift+R)
3. Verify `base: '/'` in vite.config.ts
4. Check build output: `ls dist/assets/`

### Issue: Forms Not Submitting

**Cause:** FormSubmit.co endpoints not configured

**Solution:**
1. Visit formsubmit.co
2. Create endpoints for contact and booking forms
3. Add to GitHub Secrets: `VITE_CONTACT_FORM_URL`, `VITE_BOOKING_FORM_URL`
4. Rebuild and redeploy

### Issue: Analytics Not Tracking

**Symptoms:** No data in GA4 Real-Time reports

**Solutions:**
1. Accept cookie banner (tracking disabled until consent)
2. Verify `VITE_GA4_ID` in GitHub Secrets
3. Check browser console for tracking errors
4. Verify GA4 in src/lib/analytics.ts is active
5. Wait 5-10 minutes for data propagation

### Issue: Custom Domain Not Working

**Symptoms:** Site accessible at github.io but not custom domain

**Solutions:**
1. Verify DNS CNAME record: `dig www.viv53.com`
2. Check `public/CNAME` contains `www.viv53.com`
3. Verify `dist/CNAME` exists after build
4. Wait up to 48 hours for DNS propagation
5. Check GitHub Pages settings for custom domain status

### Issue: SSL Certificate Pending

**Symptoms:** "Not secure" warning or SSL errors

**Solutions:**
1. Wait 24 hours after DNS configuration
2. Remove and re-add custom domain in GitHub Settings
3. Ensure "Enforce HTTPS" is enabled
4. Check GitHub Pages status: Settings → Pages

## Manual Deployment (Fallback)

If GitHub Actions fails, you can deploy manually:

```bash
# 1. Install gh-pages package
npm install -D gh-pages

# 2. Add deploy script to package.json
# "deploy": "vite build && gh-pages -d dist"

# 3. Build and deploy
npm run deploy

# 4. Check deployment
# Visit https://www.viv53.com after 2-3 minutes
```

**Note:** Manual deployment should only be used as a fallback. The GitHub Actions workflow is the recommended approach.

## Rollback Procedure

If deployment introduces critical bugs:

### Option 1: Revert via Git

```bash
# Find the last working commit
git log --oneline

# Revert to that commit
git revert <commit-hash>

# Push to main (triggers auto-deploy)
git push origin main
```

### Option 2: Redeploy Previous Version

```bash
# Checkout previous commit
git checkout <previous-commit-hash>

# Force push to main (use with caution!)
git push origin main --force
```

### Option 3: Disable Deployment

Temporarily disable auto-deployment:
1. Go to .github/workflows/deploy.yml
2. Comment out the workflow or change trigger
3. Commit and push
